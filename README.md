# Python Workshop

A collection of Python workshop exercises and lab scripts for introductory programming practice.

## Repository contents

- `A.py`
- `ABC.py`
- `aas.py`
- `umesh.py`
- `ABC` — an additional workshop file without a Python extension.

The original filenames are retained so the workshop material remains recognizable. Each script should be reviewed individually for its inputs and purpose.

## Run an exercise

1. Install Python 3.
2. Download the repository and open a terminal in its folder.
3. Run the script you want to explore, for example:

```bash
python A.py
```

On systems that use the `python3` command, run `python3 A.py` instead. Follow any prompts shown by the script.

## Learning workflow

Read an exercise, predict its output, run it, and experiment with small changes. Keep notes on the behavior you observe.

## Project status

These files are workshop material rather than a packaged application. A shared dependency list and automated test suite are not provided. Review imports in the selected script before running it.
